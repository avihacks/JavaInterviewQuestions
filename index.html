Sample project to explain in an interview: ShopEasy (7 lines)

An online-shopping backend split into small services. The explanations below use this same project.
  1. What it is: ShopEasy is an online-shopping backend split into four microservices: Order, Payment, Inventory and Notification.
  2. Tech stack: Java 17, Spring Boot 3, Spring Data JPA, PostgreSQL, Redis for caching, Kafka for events, and Docker.
  3. My role: I built and maintained the Order Service: REST APIs to create, view and cancel orders, with request validation and one standard error format.
  4. Communication: Order calls Payment over REST because it needs the result immediately; after payment it publishes an "OrderPlaced" event to Kafka that Inventory and Notification consume.
  5. Performance: I removed N+1 queries with JOIN FETCH, added database indexes and pagination, and cached product data in Redis with a TTL, which cut p95 latency from about 3 seconds to about 400 ms.
  6. Reliability and security: Idempotency keys prevent double payments, Resilience4j adds retries and a circuit breaker, endpoints are secured with JWT, and correlation IDs in the logs make issues easy to trace.
  7. Quality and delivery: Unit tests with JUnit and Mockito, integration tests with Testcontainers, a CI/CD pipeline, and Docker/Kubernetes deployments with health checks and Grafana dashboards.
Important: this is a sample. Replace the stack, role and numbers (like 3 s → 400 ms) with your real project details. Only claim what you can explain in depth.
